# Sample webapp

This is a sample webapp that takes the S3 endpoints and serves them in a simple UX interface.

This is just to show that the hosted data endpoints work and can be used in an application.

In reality, if I would like to open this app to the public internet the data has to be trimmed to avoid GDPR (e.g. solo propietorship `Enkeltmandsvirksomhed`). You can also be data controller and follow the legislative process.
